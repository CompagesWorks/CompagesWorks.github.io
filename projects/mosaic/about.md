MOSAIC is a Super Smash Bros. Ultimate mod manager. Enable and disable your installed mods, and download new ones from MOSAIC itself or straight from GameBanana, all in one place that keeps modding easy.

- Enable, disable, rename and uninstall mods
- 1-click install from GameBanana
- Manage plugins
- Launch the emulator from MOSAIC
- CSS editor
- See each mod's image and info
- Change character slots
