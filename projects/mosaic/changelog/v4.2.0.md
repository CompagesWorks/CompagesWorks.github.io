# MOSAIC 4.2.0

*November 2026*

4.2.0 is the biggest update since 4.0.0. It has everything from the three betas, and on top of that we went through every place where MOSAIC could lose your mods if an install, a delete or an update went wrong.

Over the past few weeks we also changed a lot of the code to make it easier to work on, and rewrote by hand some functions that could have passed for AI-generated code. The GameBanana page and the new Credits tab both have an AI Usage Disclosure if you want to know how AI was used on the software.

## <i class="bi bi-shield-check"></i> Your mods are safer

Until now, a few actions in MOSAIC could delete files for good if something went wrong halfway.

When you install a mod you already have, MOSAIC now asks before replacing it. The old version stays where it is until the new one is fully copied, and only then goes to the Recycle Bin. If the install fails or you cancel it, you still have your mod.

![The replace confirmation when installing a mod that already exists](projects/mosaic/changelog/v4.2.0/replace-mod.webp)

Files you drop on the window or pick are copied instead of moved, so the original archive stays where it was.

## <i class="bi bi-trash"></i> Uninstalling goes to the Recycle Bin

Some drives (often external ones or SD cards) have no Recycle Bin. On those, MOSAIC tells you and asks before deleting the mod permanently. Plugins and conflicting files you delete from the conflict window also go to the Recycle Bin now.

![The uninstall confirmation, which moves the mod to the Recycle Bin](projects/mosaic/changelog/v4.2.0/no-recycle-bin.webp)

These warnings use MOSAIC's own windows instead of Windows dialogs, so they look like the rest of the app.

## <i class="bi bi-archive"></i> Slot change backups

Each backup is now tied to the mod it came from, so it can only be restored on that mod. Renaming a mod keeps its backup, uninstalling it removes the backup, and the first backup is no longer overwritten. See and delete them all in **Settings > Maintenance**.

## <i class="bi bi-nintendo-switch"></i> Sending mods to the Switch

After a mod is uploaded over FTP or copied to the SD card, MOSAIC removes the files on the Switch that are no longer in your local copy, so leftovers from an old version don't mix with the new one.

## <i class="bi bi-arrow-counterclockwise"></i> Restoring a configuration

The restore now prepares the files next to your data first and only swaps them in once everything worked. If it fails, your current settings and mods list stay as they were.

## <i class="bi bi-plugin"></i> Ozone is the default plugin loader

New installs set up Ozone instead of Skyline. If you prefer Skyline, the marketplace shows which loader is active and lets you switch to the other one in a click.

![The tutorial installing Ozone and ARCropolis](projects/mosaic/changelog/v4.2.0/ozone-install.webp)

## <i class="bi bi-tag"></i> Choose the plugin version

Every plugin in the marketplace now has a version picker. The SSBU version choice moved there too: the tutorial installs the latest ARCropolis without asking, and if you need an older one, pick it from the marketplace. **Let me choose any version** opens the full list for every install and reinstall, plugin loaders included.

![The SSBU version choice with the Let me choose any version option](projects/mosaic/changelog/v4.2.0/plugin-version.webp)

The Plugins tab also shows each plugin's version next to its size.

## <i class="bi bi-arrow-repeat"></i> Safer plugin updates

When a plugin updates, MOSAIC checks that the download is a real `.nro`, keeps the previous version aside, and only replaces the plugin file. ARCropolis updates only add the files it is missing, so your ARCropolis settings are kept.

If an update breaks something, each plugin has a **Restore previous version** button. You can delete these kept versions with **Delete Plugin Backups** in **Settings > Maintenance**. For ARCropolis, **Reinstall all**, in the updates window and its marketplace menu, replaces everything from scratch, settings included, after a warning.

![The Restore previous version button on a plugin](projects/mosaic/changelog/v4.2.0/plugin-restore.webp)

## <i class="bi bi-eye-slash"></i> Hidden skin slots

Some mods tell the game how many costumes a fighter has, in `ui_chara_db.prcxml`. When that number is lower than the slots you installed, the extra skins never show up on the select screen, and nothing tells you why.

MOSAIC now spots this, lists the mods affected and offers to fix them. You can also set the count by hand with **Slot count (PRCXML)** in a mod's right-click menu, or turn the warning off in the settings.

![The hidden skin slots window listing the mods to fix](projects/mosaic/changelog/v4.2.0/hidden-slots.webp)

## <i class="bi bi-volume-up"></i> Voice mods on one skin only

A voice or sound mod normally plays on every costume of a fighter. The new **Assign to a model** option in the right-click menu of voice and sound mods moves their sounds into a skin mod on its slot, so the voice only plays when you pick that skin.

## <i class="bi bi-search"></i> Finding and sorting mods

- Sort the mods list by file size. Sizes load in the background, with a small spinner while they come in.
- Searching in the Characters tab also looks at mod names, and shows the characters with a matching mod.

![Mods sorted by file size, with the size under each mod](projects/mosaic/changelog/v4.2.0/sort-size.webp)

## <i class="bi bi-download"></i> Downloads

- The total progress of your downloads shows on the MOSAIC icon in the taskbar.
- When a mod finishes installing while MOSAIC is in the background, you get a system notification.

## <i class="bi bi-grid-3x3-gap"></i> CSS editor

The CSS editor now has a right-click menu, shows where a fighter will land while you drag it, and is translated like the rest of the app.

<video src="projects/mosaic/changelog/v4.2.0/css-editor.mp4" autoplay loop muted playsinline></video>

You can also keep several CSS layouts with **CSS profiles**: for example one with your custom movesets, and one that is safe for online play. Each profile has its own roster, hidden fighters and names. Pick a profile from the button next to the character count, and **Apply Layout** installs the one you are on.

## <i class="bi bi-chat-left-text"></i> Sending feedback

You can attach up to 5 log files to your feedback, which helps a lot when reporting a bug. If you send it without a way to contact you, MOSAIC warns you first, since we cannot ask follow-up questions otherwise.

The feedback page now says what it is for: problems with MOSAIC itself. If the emulator or the game crashes, a button takes you to the Compages Works Discord, where you can get help with that. It also asks you to describe what happened instead of just "I need help", to add a contact if you want a reply, and to write in English if you can.

![The feedback window with attached log files](projects/mosaic/changelog/v4.2.0/feedback-logs.webp)

## <i class="bi bi-palette"></i> Tutorial and windows

- The tutorial uses the app's theme, with shorter welcome and finish screens.
- The tutorial progress dots animate when steps appear or disappear.
- The tutorial and windows grow and shrink smoothly instead of jumping.
- Beta versions show a notice and a **Beta** badge in the title bar.
- Alpha versions show a blue **Alpha** badge in the title bar and a warning that asks you to back up your mods, with a button that takes you to the config backup.
- Alpha and beta versions have their own app icon, with an **Alpha** or **Beta** ribbon.

## <i class="bi bi-stars"></i> Other changes

- The Credits tab has an AI Usage Disclosure.
- The Discord button leads to the Compages Works server.
- The slot changer overview shows slots past `c15`.
- Sort and category selectors got icons.
- Logs only keep what helps for bug reports.

## <i class="bi bi-bug"></i> Fixes

- Changing one setting no longer saves every other setting again.
- Names with quotes display correctly.
- "Disable all mods on download" works when a disabled mod has the same name, and MOSAIC warns you when a new mod stays enabled because of one.
- The download speed no longer jumps around.
- GameBanana install errors show inside the app, and a cancelled install shows as cancelled instead of failed.
- A failed file move during a slot change no longer leaves a half-copied file in the mod.
- A plugin update no longer leaves the old version in place when the new file has a different name.
- Mod file renames and deletes can no longer reach outside the mod folder.
- No more "punycode" warning in the logs.
- The grey text in windows is easier to read.

## <i class="bi bi-gear"></i> Under the hood

The biggest parts of the app (Characters, GameBanana, status bar, CSS editor, settings, tutorial) were split into smaller files, and the main process modules were grouped into folders. Nothing changes for you, but fixes and new features will be quicker to ship.
