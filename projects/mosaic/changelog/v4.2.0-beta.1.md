# 4.2.0-beta.1

*November 4, 2026*

### DO NOT INSTALL THIS BETA

(Note for MacOS : For some reason GitHub today can't make the macos build, so it will not be available right now.)

#### Release notes : 
Over the past few weeks we’ve changed a lot of the code to make it easier to work on. New features, bug fixes and general changes should all be quicker to make now. Some features were split into several files and rewritten along the way.

We also started rewriting by hand some functions that could have passed for AI-generated code, so the latest changes rely less on AI than before.

The GameBanana description now has an AI Usage Disclosure. It only covers the lead developer, but since he was the only contributor to these changes, that’s where to look if you want to know how AI was used in this update.

#### Changelog : 
- Add a file size sort option to the mods list, with each mod's size shown while it is selected
- Add the version of each plugin next to its size in the Plugins tab
- Add an icon to the sort and category selectors in the Mods tab
- Add the total progress of mod downloads in the taskbar
- Add a system notification when a mod is installed while the app is in the background
- Add "Assign to a model" in the right-click menu of voice and sound mods, it moves their sounds into a model mod on its slot so the voice no longer plays on other slots
- Add the search of mods in the Characters tab, searching now shows the characters that have a matching mod
- Change the tutorial look to match the rest of the app
- Change the tutorial welcome and finish screens to be clearer and shorter
- Change the tutorial progress dots animation when steps appear or disappear
- Fix changing one setting saving every other setting again
- Fix mod and file names with quotes not displaying correctly
- Remove most of the noise in the logs, only what helps for bug reports is kept
- Change the internal structure of the biggest parts of the app (Characters, GameBanana, status bar, CSS editor, settings, tutorial), nothing changes for you but fixes and new features will be easier to ship
