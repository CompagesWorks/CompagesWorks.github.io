# 4.0.0

*October 3, 2026*

FightPlanner is now **MOSAIC**. Version 4 is a full rewrite (TypeScript, Electron 41).
Here is everything that changed since FightPlanner 3.3.33.

#### ✨ Highlights
- **A brand-new interface**, designed from the ground up for the best possible user experience and to make the app easier to use than ever
- **1-click install now correctly installs every mod**
- Real Switch hardware support: send your mods straight to your console
- Discover tab: browse and download GameBanana mods without leaving the app
- Social features: profiles, friends, feed and badges
- Character Select Screen (CSS) manager
- Native Linux and macOS support
- Backup & restore, mod profiles and batch testing

#### 🎨 New interface
- Completely redesigned UI, thought through to give the best user experience and make everything simpler and more intuitive
- New status bar with expandable downloads and conflicts, plus download speed
- Splash screen, new animations and a reorganized Settings with icons
- Responsive layout that adapts to any window size
- Sounds for tab switching, errors, completed actions and downloads; custom sounds and option to disable them
- In-app tutorial that now install ARCropolis automaticaly
- Zoomable images in mod details and stacking notifications

#### 🆕 New features

##### Real hardware
- **Send to Switch** over FTP or directly to an SD card/disk, with Quick sync (only newly downloaded mods) and Full sync

##### Discover & Social
- Download GameBanana mods directly in the app, with dependency checks and dependency downloads
- Filters (Characters, Stages, Sounds, Effects…), sorting (popularity, release date, downloads) and download counts
- NSFW filter (hidden by default) and privacy settings for mod visibility
- Browse Discover without creating an account, and option to disable Social entirely

##### Characters, slots & CSS
- **CSS Manager** is officialy there
- **Change Slot** rewrite: custom slots up to c255, multi-character mods, conflict-aware dialog, "Review your changes" step
- Smart Rename tool and "Make Echo slot" button
- Sound and voice files now follow slot changes; Ice Climbers support
- Automatic slot change up to c255, slot labels in the Characters tab
- Moveset button in the Characters tab (with add-to-CSS support)
##### Library management
- Multi-select (Shift/Ctrl) and bulk enable/disable
- **Profiles**: create and switch between mod setups
- **Backup & restore** and export your mod list
- **Batch testing** to find the mod causing a crash
- Info editor with custom preview image, "Browse Files" and single-file deletion
- Conflict system is rewritten and now false-positive are less possible
- Auto-refresh when files change in the file explorer
- Warnings for a wrong library path or an unnamed mod ("mod-XXX"), and a prompt to read bundled .txt files
- `.FPP` v2 format

##### Plugins
- Plugin marketplace (including CSK Collection and One Slot Effects)
- ARCropolis install from the tutorial, ARCropolis check, and downgrade to 4.0.8
- Plugin path warning and improved plugin update handling

#### 🔧 Under the hood
- Migrated to TypeScript and Electron 41
- Custom JS support
- Faster startup
- Many dependency security updates

This final release too fix somes bug that happend to beta13.
