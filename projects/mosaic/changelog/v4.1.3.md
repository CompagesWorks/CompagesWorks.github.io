# 4.1.3

*October 28, 2026*

#### Release notes
This version improves the app and fixes bugs that had been around since before the first beta releases.

It also fixes problems left over from early contributions made during internal development, before any beta was released. Some of that code was probably written with AI or vibe-coded. We went back over it and fixed it, so the app should be more stable now.

We took the time to fix every bug we could find. If you run into one we missed, please report it.

#### Changelog :
* Add caching to the UMC API
* Add a loading indicator for UMC images in movesets
* Add a backup option before changing slots, restorable from the mod's right-click menu
* Add a choice to keep and update an existing config.json or generate a new one when changing slots
* Add transplanted effects when changing slots
* Install extra folders from a mod archive (like mastaklo_movesets) into the ultimate folder
* Show manually installed mods in the Downloads tab
* Require a restart after resetting app data
* Prevent moving several slots to the same target slot
* Improve UI
* Load gsap and lottie locally instead of from a CDN
* Ship only the tools needed for each platform
* Add native Apple Silicon support for ParamXML
* Fix script injection through the mod info URL
* Fix wrong character ID for Ice Climbers
* Fix slot changing for linked characters (Trainer, Pyra/Mythra, Bowser/Giga Bowser)
* Remove the stages tab
